# Source-course boundary

The two local folders named `聪明的跨境人都在学的亚马逊广告高阶课，每天10分钟，手把手教你成为广告实战高手` and the `(1)` variant contain lesson videos. File names and lesson titles can support a curriculum map, but they do not prove the lesson's spoken method, current Amazon UI, or account results.

When the user asks to distill these folders:

1. Confirm access is authorized by the user.
2. Use only short summaries, reusable procedures, and evidence gaps. Do not output transcripts or long paid-content excerpts.
3. Label title-only observations as grade D and video-reviewed observations as grade C until a reproducible account export or experiment upgrades them.
4. Preserve source folder, filename, timestamp/position, and capture status in the trace.
5. Separate curriculum-derived heuristics from current Amazon policy or UI facts. Verify changing platform details from current official documentation before publishing.

The Skill can operationalize a method only when its trigger, inputs, outputs, failure mode, and validation criterion are explicit. Otherwise keep it as a note or `待确认` question.
