# Report to Action Map

| Source | Can establish | Cannot establish by itself | Typical Codex output |
|---|---|---|---|
| Campaign report | spend, sales, orders, impressions, clicks, budget usage in its window | causality, live state, future rank lift | anomaly list and bounded test |
| Search-term report | query, target, clicks, spend, orders, sales, relevance evidence | universal negative thresholds | promote / observe / negative proposal |
| Placement report | placement-level delivery and efficiency | why placement changed | placement test plan |
| Business report | traffic and conversion context | ad attribution correctness without matching window | conversion context check |
| Inventory/eligibility export | available or blocked supply signals | future replenishment certainty | traffic-risk stop rule |
| Listing/creative brief | content gaps and testable hypotheses | conversion lift before a test | creative brief and validation metric |

Always attach the report window, marketplace, currency and source path to the conclusion.
