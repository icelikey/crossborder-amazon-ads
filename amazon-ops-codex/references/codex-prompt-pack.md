# Codex Prompt Pack

## Daily pulse

> Use `$amazon-ops-codex`. Read the attached intake and exports. Produce a 10-minute daily pulse for `<marketplace>` and `<date_range>`. Separate facts, gaps and hypotheses. Rank no more than three actions; choose one reversible action with a stop rule, owner, deadline and validation metric. Do not change the account.

## Search-term review

> Use `$amazon-ops-codex` plus the existing ads audit skill. Classify each query as promote, observe, negative exact, negative phrase or cannot determine. Show the evidence row, product-fit rationale, expected risk and rollback note. Do not invent a threshold.

## Weekly review

> Reconcile the attached reports before interpreting them. Write Fact / Explanation / Hypothesis / Action / Result sections, then produce a queue for today, this week, observe and blocked. Keep the same marketplace, currency, attribution window and date range across comparisons.

## Seasonal readiness

> Build a prepare / live / review plan. Check inventory and eligibility before traffic expansion. Mark marketplace policy and dates as `待确认` unless supplied by a current authoritative source. Include owners, a rollback plan and post-event observation window.
